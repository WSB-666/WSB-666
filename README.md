## 🚀 Featured Projects

### 🚁 iCAN 城市应急物资投送 · UAV Autonomous Delivery

基于 **ROS 2 + Gazebo** 的无人机自主导航与物资投放系统。

| 模块 | 实现 |
| :--- | :--- |
| 自主导航 | Nav2 路径规划 + 穿窗几何约束 |
| 目标识别 | OpenCV 多尺度模板匹配（识别得分 0.966 / 0.954） |
| 轨迹可视化 | 自研节点：`/uav/odom` → `/uav/path` → RViz |
| 任务结果 | **4/4 投放 · 74 s · 降落偏差 0.00 m** |

### 🤖 fishbot · ROS 2 自主导航机器人

- URDF + Xacro 多部件建模（10 link / 9 joint）
- Gazebo 物理仿真 + `ros2_control` 差速驱动
- 激光雷达 / IMU / 相机 多传感器接入
- Nav2 建图、定位与单点 / 路点导航
